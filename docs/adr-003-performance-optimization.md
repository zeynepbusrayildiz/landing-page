# ADR-003: Performance Optimization

## Problem
Lighthouse performans skoru düşük çıktı (özellikle mobile).

## Yapılanlar
- PNG görseller WebP formatına çevrildi
- Görsel sayısı azaltıldı
- Hero slider kaldırıldı
- Image lazy loading eklendi

## Sonuç
Performans iyileştirildi ve hedef skora yaklaşıldı.
