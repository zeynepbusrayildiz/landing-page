# ADR-001: UI Component Architecture

## Karar
UI bileşenleri (Button, Card, Modal, Input, Accordion) ayrı component dosyalarına ayrıldı.

## Neden?
- Tekrar kullanılabilirlik
- Kodun okunabilirliği
- Bakım kolaylığı
- Ölçeklenebilir yapı

## Alternatif
- Tüm UI’ı tek dosyada yazmak (reddedildi)

## Sonuç
Modüler component yapısı seçildi.
